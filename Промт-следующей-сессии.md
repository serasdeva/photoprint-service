## 1. Что за проект

- Node.js 24, Express 4, EJS, Sequelize 6 + SQLite, JWT в httpOnly-cookie, CSRF double-submit, Helmet CSP, multer.
- Telegram-бот (Telegraf, long polling) живёт в том же процессе, что и сайт: запускается из `server.js`, БД одна.
- Публичные страницы: главная, услуги + карточка услуги, галерея, контакты, политика.
- Админка `/admin`: дашборд, услуги, галерея, заявки, настройки сайта, настройки Telegram.
- Деплой: Ubuntu + systemd + nginx + certbot, скрипты в `deploy/`.

Структура: `app.js` (middleware/роуты), `server.js` (запуск + graceful shutdown), `config/` (БД, миграции, драйвер SQLite), `controllers/`, `models/`, `routes/`, `middleware/`, `views/`, `public/`, `telegram/`, `migrations/`, `tools/`, `tests/`.

Полезные маршруты: `GET /healthz` (проверка БД), `GET /sitemap.xml`, `GET /robots.txt`, `POST /api/orders`, `GET /api/services`, `GET /api/gallery`.

## 3. Правила работы

1. **Только запрошенный объём.** Не добавляй фичи «заодно»: сначала задача, потом отчёт.
2. **Не коммить без просьбы.** Пользователь коммитит сам.
3. **Definition of done:** `npm run lint`, `npm run format:check`, `npm test` зелёные + smoke затронутых маршрутов.
4. **Язык:** интерфейс и комментарии — русский, код и имена — английский.
5. **Windows/PowerShell:**
   - не читай UTF-8 через `Get-Content` без `-Encoding` — получишь мохнатую кириллицу (уже случалось);
   - для правок используй apply_patch; если файл в CRLF и патч не применяется — переведи в LF через `[IO.File]::ReadAllText` / `WriteAllText` с `UTF8Encoding($false)`;
   - `npm audit fix --omit=dev` вычищает dev-зависимости (`supertest` и др.) — после него нужен `npm install`.
6. **Безопасность:** не ослабляй CSP, CSRF и rate limit ради удобства. При удалении CDN правь и `style-src`, и `font-src`.
7. **Секреты:** `.env` не трогать и не печатать; в отчётах маскировать.

### 4.5 Составной индекс под фильтр заявок — ЗАКРЫТО 31.10.2026

Исходная проблема подтвердилась на копии рабочей базы: `WHERE status = ? ORDER BY createdAt DESC`
шёл через `SEARCH … USING INDEX orders_status_idx (status=?)` + `USE TEMP B-TREE FOR ORDER BY`,
то есть SQLite отдельно досортировывал каждую выборку.

- `migrations/0002-orders-status-created-at.js` (новый) — создаёт
  `orders_status_created_at_idx ON Orders (status, createdAt)` и удаляет одиночный
  `orders_status_idx`. Удаление безопасно: все запросы только по `status` идут по префиксу
  нового индекса (сверено планами `EXPLAIN QUERY PLAN` до и после — см. ниже).
- `models/Order.js` — в `indexes` составной заменил одиночный, иначе `sync({alter:true})` в
  development возвращал бы удалённый индекс.
- `tests/app.test.js` — тест `migrations create order indexes and stay idempotent` теперь ждёт
  составной индекс, отсутствие `orders_status_idx` и **план без `TEMP B-TREE`** для запроса админки.

Планы на копии рабочей базы (6 заявок), до → после миграции:

| запрос                                                            | до                                          | после                                        |
| ----------------------------------------------------------------- | ------------------------------------------- | -------------------------------------------- |
| дашборд, 5 новых (`status='new' ORDER BY createdAt DESC LIMIT 5`) | `orders_status_idx` + TEMP B-TREE           | `orders_status_created_at_idx`, без B-TREE   |
| админка, `?status=…`                                              | `orders_status_idx` + TEMP B-TREE           | `orders_status_created_at_idx`, без B-TREE   |
| счёт новых / `GROUP BY status`                                    | covering `orders_status_idx`                | covering `orders_status_created_at_idx`      |
| список без фильтра                                                | `orders_created_at_idx`                     | без изменений                                |
| «Мои заявки» бота                                                 | `orders_telegram_chat_id_idx` + TEMP B-TREE | `orders_telegram_chat_created_at_idx` (4.8a) |

Проверено раннером `config/migrations.js` на копии `data/photoprint.sqlite` в `%TEMP%`:

## 6. Грабли, на которые уже наступали

- **Sequelize + SQLite:** `afterConnect` не вызывается, соединения кешируются по `uuid` (транзакция = отдельное соединение). Прагмы ставить обёрткой драйвера (`config/sqliteDriver.js`).
- **`sync({ alter: true })`** в development может пересоздать таблицу — индексы дублируются в модели, миграции всё равно нужны для прода.
- **`sequelize.sync()`** создаёт только отсутствующие таблицы; новые индексы в проде — исключительно через `migrations/`.
- **Rate limit логина** 5/15 мин — в тестах сессия кешируется в `loginJar()`, иначе тесты падают на 6-м входе.
- **Тестовый `data/sessions`** подменяется через `SESSION_DIR`, иначе тесты чистят реальные сессии разработчика.
- **CSP:** `frame-src https:` нужен для карты из настроек; `img-src` не должен потерять `data:` и `blob:` (галерея).
- **PowerShell + UTF-8** — главная причина порчи файлов; при сомнении проверяй первые байты на BOM и наличие кириллицы в диффе.
- **FA-сабсет:** имена берутся только из `all.min.css`, часть правил — с алиасами в одном селекторе; `sparkles`, `printer`, `monitor` в FA Free отсутствуют.
- **Автотест иконок сканирует литералы `fa-*`** по всем `views/` и `public/js` — не называй так id и классы: id `fa-icon-options` тест принял за иконку и потребовал глиф. Поэтому datalist называется `icon-options`.
